# Sonsuz Sigara Molası Hesaplayıcısı

## Giriş

Bu proje, insanlık tarihinin en büyük bilimsel atılımlarından biridir. Sigara molasının iş verimliliği üzerindeki etkilerini kuantum düzeyinde analiz eden, tamamen bilimsel ve ciddi bir yazılımdır.

### Neden Bu Proje?

- Çünkü çay demleme simülasyonları çok sıradan kaldı.
- Çünkü iş yerinde "biraz hava alayım" demek artık yeterli değil, bilimsel hesaplama gerekiyor.
- Çünkü sonsuzluk kavramını sigara molasıyla birleştirmek insanlığın kaderini değiştirecek.

## Kurulum

Python 3.x yeterlidir. Hiçbir kütüphane gerekmez çünkü bu kadar ciddi bir şey için pip'e ihtiyaç yoktur.

```bash
python sigara_mola.py
```

## Kullanım

Program çalıştığında size kaç tane "stratejik sigara molası" alacağınızı sorar. Sonra her biri için optimal süreyi hesaplar, bekleme simülasyonu yapar ve size hayatınızı değiştirecek tavsiyeler verir.

## Bilimsel Temel

Bu algoritma, "Mola Teorisi"nin temel prensiplerine dayanır:
1. Sigara içmek = düşünmek
2. Düşünmek = verimlilik
3. Daha çok mola = daha çok verimlilik (bu formül tartışmalıdır ama biz tartışmayız)

## Uyarı

Bu yazılım gerçek sigara içmeyi teşvik etmez. Sadece molaların matematiksel güzelliğini kutlar. Sağlık Bakanlığı uyarır: Sigara sağlığa zararlıdır, ama bu kod değildir.
